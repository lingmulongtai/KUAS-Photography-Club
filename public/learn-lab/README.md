# Learning-lab assets (design proposals)

Used by the unpublished design proposals under `/learn/lab/`. All files are CC0 (public domain)
from [Poly Haven](https://polyhaven.com/), unchanged except that the tone-mapped panoramas were
resized to 4096×2048 JPEG and 640×320 thumbnails.

Models (1k textures, glTF): `marble_bust_01`, `horse_statue_01`, `tea_set_01`, `food_apple_01`,
`food_pomegranate_01`, `Camera_01`, `chess_set`.

Panoramas (`<name>.jpg` seen behind the subject, `<name>_1k.hdr` for lighting):
`ninomaru_teien` (Nagoya Castle Ninomaru garden), `autumn_forest_04`, `shanghai_bund`,
`studio_small_09`, `the_sky_is_on_fire`.

The drawing mannequin, the torii gates and the pinwheel are generated in code
(`src/scripts/lab/`).
