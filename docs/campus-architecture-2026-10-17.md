# 太秦キャンパスの建築モデル・大文字山・御苑の交通

## 実装と根拠

太秦キャンパスの近接モデルを、PLATEAU LOD1の一律な窓帯付き押し出しから、図面と竣工写真を参照した棟別モデルへ置き換えた。参照写真をテクスチャとして転載せず、形状・材質をコードで生成する。

| 対象 | モデルへ反映した構成 | 主な根拠 |
| --- | --- | --- |
| 北館 | 120 × 24 mの構造寸法、4層、8 m幅の地上通路、吹き抜け、上階の渡り、端部ガラス面、不規則な北側開口、勾配屋根 | 京都市の平面・立面・断面、設計者の竣工写真 |
| 東館 | 33 × 45 mの構造寸法、4層、北館との17.5 mの離隔、中庭側バルコニー、寄棟形状 | 同図面と写真 |
| 北―東連絡通路 | 3Fの直線通路、床・屋根・ガラス・細い支柱・下部梁、両端の出入口、通路下の空間 | 3F平面図、PLATEAU実外周、現行大学マップ |
| 北―西連絡通路 | 斜めの接続、北館側から西館側への床高差、屋根とガラス、両端の出入口、通路下の空間 | PLATEAUの独立した連絡橋外周、現行大学マップ、竣工写真 |
| 西館 | 中庭側の奥まった3Fテラス、4Fの張り出し、各階で異なるガラス面・床端、3連の外階段、木の段床とテーブル | 日本建築学会のテラス調査、施工者の中庭写真 |
| 南館 | 5層の学術棟、手前の段状テラス、両端のガラス室、横断通路、時計、屋上の勾配面と設備用平場 | 現行大学マップ、施工者の正面航空写真・中庭写真 |
| 南館大階段 | 4区間、108段の踏面と蹴上げ、各階の踊り場、中央と両側の手すり、梁、横断通路の支持柱 | 正面航空写真の4つの階段群と5つの接続レベル。細部寸法は写真からの推定 |
| 国際学生寮A | 南西側の細い8階部分、南向きの窓・バルコニーと間仕切り、西端のガラス面 | 大学の寮A外観・仕様。南館全体を8階にしない |
| 中庭 | 芝生、軸線と斜めの園路、建物や階段を避けた植栽、段床・ベンチ・低い照明 | 現行大学マップと中庭竣工写真 |

共通の地上階高さを使い、地下階を含むLOD1の高さから階数を算出しない。PLATEAUの屋根外周から得た約1.58度の棟の回転を反映する。外形の位置合わせには元の測量データを使うが、公開図面がない西・南館の詳細寸法、通路の床高差、寮の正確な内部境界は写真と外周からの推定であり、実測・施工用モデルではない。

北・東館の京都市資料は2013年の建設計画で、西館と南館の増築前のもの。増築後の構成には2025年更新の大学マップと竣工写真を優先した。北門前のGoogle Street Viewも開いたが、この実行環境ではパノラマ画面が黒く、画像の目視照合はできなかった。未取得のStreet Viewを検証済みの根拠には含めない。

## 表示と描画

- 生成形状は74,730三角形、頂点属性8,070,840 bytes。外部の高容量3Dモデルや画像の追加転送はない。
- 近接時のみ表示し、不透明な建物と透明なガラス手すりの2描画にまとめる。手すりは深度を参照するが深度を書き込まず、太い不透明板として描かない。
- レンガ目地、窓割り、金属屋根の継ぎ目は画素幅でフィルタする。屋根の平場と床の共面を避ける。
- 粗い旧キャンパスの建物は色の描画と影の描画の両方から除外する。近接時は影の範囲を絞り、架空の青緑の発光リングを表示しない。
- キャンパスの周回距離と注視高さを建物に合わせる。縦長画面では全棟が収まり、横長画面では案内カードの左側にモデルを置く。

## 大文字山と御苑

- VIEW「大文字山」は火床付近から西南西の京都市街を眺める固定地点。
- SPOT「大文字」は山の西側から大の字を中心に周回する。地図の地点と撮影記録ページも追加した。
- スポットの「斜めから」「真上から」ボタンと関連イベントを削除した。
- 御苑の境界で一般車の経路を分割し、内部の経路を除外する。烏丸通・丸太町通など周囲の公道を保持する。角で車線の横ずれが敷地内へ入る場合も、利用可能な幅へ制限する。
- これは一般の通過車両のシミュレーションを抑止する処理であり、許可車や指定駐車場を含む現地の全車両が禁止されているという説明ではない。

## 検証

- `npm test`：73件通過。形状の光線交差、表裏、吹き抜け、橋の下部と出入口、段の単調な上昇、踊り場の通行、植栽との衝突を含む回帰テスト。
- `node tools/verify-gyoen-traffic.cjs`：配布道路データと実際の`buildCars`を使用。11,837台を600秒相当・121時点で観測し、御苑内0件。烏丸通3,098件、丸太町通3,037件の観測で公道の車が保持されることも確認。CIにも追加。
- `npm run check`：166ファイル、エラー・警告・ヒント0。本番ビルドと`node tools/verify-public-build.mjs`で公開45 HTML・仮の撮影記録6件の除外・言語リンクを確認。
- ブラウザ：19スポットの到着表示、VIEWとSPOTの大文字山の別構図、大学の昼夜表示、390px幅で横はみ出しがないこと、角度ボタンが存在しないことを確認。
- 390px幅のブラウザで、4回の横ドラッグにより大学と京都タワーは約-441.6度、展望は約+441.6度回転。展望時の眼の位置の変化は0.001m未満。これはブラウザ上のポインター操作の実測であり、実機タッチの受け入れ確認ではない。
- ローカルの3Dコードによるブラウザエラーはなし。Instagramの第三者iframeが出す既知のエラーは3Dの描画エラーとは別に確認した。

実機スマートフォンでの今回のモデルの見え方・負荷と、現地測量に基づく寸法精度は未検証。
