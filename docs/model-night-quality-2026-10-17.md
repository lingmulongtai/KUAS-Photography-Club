# 京都モデル・西側市街地・夜景の改善（2026-10-17）

対象は `3158dd9` 公開版からの差分。大学と京都タワーの形状は今回の変更対象から除外した。既存の地形・航空写真・日英表示・公式Instagram埋め込み・タッチ操作を維持する。

## モデルを確認して変えたこと

1440×1000の昼景で、東寺、八坂の塔、清水寺、平安神宮、金閣寺、京都御所、龍安寺、渡月橋を巡回した。屋根は上向きの面に対するraycastと有限座標・外形・三角形数の検証も行った。

| --- | --- | --- |

## 大学から嵐山までの建物の抜け

元のPLATEAUデータには住宅が存在した。エクスポーターは将軍塚と大学の周辺だけを優先し、それ以外で将軍塚から9km以上では、面積150m²未満かつ高さ14m未満を除いていた。嵯峨野の一部タイルでは、元の1,281棟中少なくとも1,184棟がこの条件に該当していた。

大学～渡月橋の線分から1km以内を近景地域へ追加し、小住宅と輪郭の詳細を復元した。14m²未満の微小建物、小さな無壁舎の除外、遠い市街地の既存予算は維持する。Pythonの地形サンプラーには、描画側と同じ嵐山10m格子・120m境界の合成を加えた。

PLATEAU京都市2025年度LOD1の対象800タイルを取得し、元データから全体を再生成した。

| 指標 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 箱型建物 | 247,658 | 260,190 |
| 輪郭保持建物 | 18,754 | 21,960 |
| 合計 | 266,412 | 282,150 |
| 配信gzip | 1,848,925 bytes | 1,972,029 bytes |

15,738棟増、配信は123,104 bytes増（約6.7%）。西側の500m四方の3区画に各500棟超が存在することを、実際の配信バイナリを本番ローダーで復号する回帰テストで確認する。実際の棟数を無視してランダムな建物を足す処理はない。

出典・取得先・ライセンスは [tools/kyoto-data/README.md](../tools/kyoto-data/README.md) の既存PLATEAU/GSIクレジットを適用する。生データとPython環境は `cache/` のみで、Gitへ含めない。

## 車の不具合と夜景の演出

- 車のテールランプにあった逆順の `smoothstep` を、昇順の計算の補数にした。逆順のedgeは[GLSL仕様](https://github.com/KhronosGroup/OpenGL-Refpages/blob/main/gl4/smoothstep.xml)上未定義。
- 車の光源をGL_POINTSから、画素未満の位置を維持するインスタンス四角形へ変更した。最低4pxの範囲に滑らかなGaussianを描き、面積で明るさを補正する。遮蔽のdepth testは維持する。
- 街路灯も同じ方式で滑らかにし、遠方では光の裾を少し広げた。
- 静止した窓・街路灯・道路の発光だけに、二つの低周波の正弦波を加えた。900m～6kmで徐々に振幅を増やす。車には掛けない。点滅のオン／オフやフレームごとの乱数は使わない。
- `prefers-reduced-motion` では既存の時刻uniform停止に従い、この揺らぎも停止する。
- 夜のbloom強度は最大12%増、radiusは0.5→0.68。昼は元の値。HDRの不正値除去とbloomのLOD0サンプリング修正を維持する。
- 画面全体の粒子ノイズは静止させた。動く画面ノイズが街明かりの揺らぎに混ざるのを防ぐ。

## 検証と再現

- `npm test`：60件成功。屋根の上向き面、塔の外形・高さ・予算、龍安寺の15石、建物切り取りと標高保持、配信建物の西側密度を含む。
- `npm run check`：160ファイル、error/warning/hintすべて0。
- Node 24でAstroビルド成功、`node tools/verify-public-build.mjs`：44 HTML、sampleの非公開とリンク整合性を確認。
- Pythonのエクスポーター回帰テスト2件成功。住宅の保持・小型無壁舎の除外・地域格子の境界補間を確認。
- Headless Edge / WebGLの光源単体テスト：1画素を32段階で移動した光の総輝度の変動は約1.05%。背面のヘッドライトは0、後方から見るテールランプは発光。時間だけを変えた車の輝度差は0。
- 同じGPUテストで、6km先の街路灯の10秒間の振幅は約12.97%、60Hz換算の最大1フレーム差は約0.11%。この数値は分離した光源の試験結果であり、街全体の輝度変動やスマホ実機の結果ではない。
- 地点18か所の移動、地図ラベル、JA/EN、WebGL無効時、ドラッグ・ネイティブtouch入力の既存ブラウザ回帰を確認。390px幅の4回スワイプは見回し約+424.6°、周回約−424.6°。縦スクロールも維持。地形GPUバッファの新規確保は1回。

光源単体テストは、PlaywrightとそのChromium、または対応するインストール済みブラウザが必要：

```sh
node tools/verify-car-lights.cjs
```

Playwrightが別の場所にある場合は `PLAYWRIGHT_MODULE` にモジュールの場所を指定する。WindowsのEdgeでは `PLAYWRIGHT_CHANNEL=msedge` を指定できる。ソースの光源実装をesbuildで一時的に束ね、localhostで試験する。

```sh
python -m unittest discover -s tools/kyoto-data -p 'test_*.py'
```

スマホのviewportとtouch入力の検証は、スマホ実機のGPU・発熱・Safariの検証の代用ではない。iOS/Android実機の今回の見た目と性能は未確認。PLATEAUはLOD1であり、手作りの寺院モデルも現地測量・文化財復元・夜間の実照明を保証しない。
