## 修正

- 白いモノコックの塔身を展望室の下で止め、窓を白い外皮が覆っていた構造を解消する。
- 横に広い楕円断面の二層の展望室、青い曲面ガラス、赤橙色の外周リングと曲線リブを作る。
- 展望室の上を、白い円筒、赤白の角形の柱、点検はしご・手すり、避雷針へ分ける。従来の長い円錐を廃止する。
- 屋上の青いガラスの鉢形ラウンジ、細い金属格子、青い照明の縁、ホテルとの短い接続部を作る。
- ホテルを丸い角、9階分の連続窓帯、茶色の水平材、屋上の手すりと設備室へ変更する。
- 夜の白い部分がブルームで膨らんで形を消さないよう発光量を調整する。
- 塔を中心とする全周のカメラを保ち、初期距離を320mから260mへ近づける。

## 負荷と検証

- モデル全体は **34,048三角形**。36,000三角形未満をテストで制限する。名所全体を既存の1メッシュへ統合し、描画回数・テクスチャ・外部モデルのダウンロードを増やさない。細部の生成は初期化時だけで、フレームごとの再生成はない。
- `npm test`: **24件成功**。全高、有限な座標・法線、三角形予算、展望室二層・ラウンジ・接続部を四方向から見たガラスの露出をレイで検証する。
- `npm run check`: **123ファイル、error/warning/hint各0**。
- `npm run build`: ASCIIの検証コピーで成功。既存の日本語OneDriveパスによるビルドプロセス終了の問題を避けるため、前回と同じコピー先を使う。
- 実際のChrome / NVIDIA RTX 4050 / ANGLE D3D11で、昼夜・90°/180°/270°/360°の回転を確認。アプリのブラウザ警告・エラーなし。
- 通常描画、1487×1080px、120フレームで間隔の中央値 **16.7ms**、95パーセンタイル **16.8ms**。このPCでの一例であり、スマホの性能保証には用いない。
- 390×844のブラウザ幅で頂部・塔身・ホテルが画面に収まり、横はみ出しがないことを確認。スマホ実機の検証とは区別する。
- 同じ照明・実寸スケールの修正前／修正後正面／修正後背面を、ローカル専用の造形比較画面で確認・撮影した。比較用の照明は本番の街のシェーダーとは異なる。比較用コードはリポジトリにも本番用ソースにも含めない。
- レビューで見つけた屋上とラウンジの0.4mの隙間は、接続部を追加して修正し、同じ高さのレイ検証を加えた。
- スケジュール、ガイドライン、連絡先、入部先、管理画面APIへの差分なし。前回の地面・植生・カメラのローカルコミットを保持する。
